## 后续案例登记字段

以下仅为字段规范，不是一个案例：

| 字段 | 取证要求 |
| --- | --- |
| Case ID | 取得案例后分配唯一标识 |
| 原始资料 | Source ID、URL、发布日、时间戳或原文定位 |
| 身份与性质 | 核实本人叙述；区分实际成交、模拟、事后图表分析与观察名单 |
| 股票代码与市场 | 仅记录原始披露信息 |
| 交易日期与方向 | 分开记录发布日期和交易日；未知字段不推断 |
| 交易类型和市场环境 | 仅按原文归类，未说明时标为 UNVERIFIED |
| 入场依据和执行 | 简短摘录或准确转述；是否披露成交价/时间分别记录 |
| 初始止损依据 | 区分计划止损与真实退出；未披露则注明 |
| 卖出及管理 | 分批、移动止损、加减仓及退出原因，仅记录明确披露部分 |
| 最终结果 | 区分本人报告与独立验证，不能用随后价格变化代替真实收益 |
| 中文解读 | 与原始事实分开，标注解释限制 |
| 规则关联与证据状态 | 关联 Rule ID，给出 VERIFIED/PARTIAL/UNVERIFIED/CONFLICTING 及理由 |

禁止自行推断未披露的成交价格、成交时间、仓位、资金或损益。原话没有说明例外时记录“未披露”，不写“无例外”。
