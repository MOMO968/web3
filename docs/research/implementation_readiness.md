## 编码前门槛（后续审查流程，不是交易规则）

1. 取得可复核的原始发言或案例，具有 URL、发布信息、精确定位、短摘录或准确转述及中文解释。
2. 确认规则的适用交易类型、市场环境、使用时期、执行条件、参数和例外；缺失项继续标注未知。
3. 区分固定逻辑和主观决策，明确哪些部分无法忠实机械化，不用研究者参数掩盖缺口。
4. 用原始案例核对解释的一致性，不推测未披露成交价或用回测优化参数。
5. 明确数据可得性和时间语义，避免未来信息；未知的时间定义须先澄清，不擅自补齐。
6. 证据状态不等于实现就绪；即使 VERIFIED，也须检查输入、阈值和决策优先级。

当前仅研究目录和结构可供后续接续。六项包导入测试即使通过，也不能作为交易系统已还原的证据。
